# Implementation Plan: SpiderWidget

## Overview

Собираем виджет из `SPEC.md` вертикальными срезами: после каждой задачи
`SpiderWidget.exe` запускается и делает чуть больше, чем раньше. Сначала —
окно с головой и падение, потом ноги и ходьба, потом опоры (окна, иконки),
лазание и срывы, затем мышь (бросок, охота) и в конце корзина.

Задачи с подробными критериями — в `tasks/todo.md`.

## Architecture Decisions

- **Логика без WinForms.** `Physics`, `Legs`, `SpiderBrain`, `Grab`,
  `RecycleBin.Check` — чистые классы: на вход `dt`, опоры, курсор, `Random`;
  на выход позиции и состояние. Окно только рисует и передаёт ввод. Так всё
  поведение тестируется xUnit без экрана.
- **Окно размером с паука**, двигается вместе с ним (`SetWindowPos`), а не
  оверлей на весь экран — проще click-through и drop.
- **Один таймер 60 Гц** в UI-потоке (`System.Windows.Forms.Timer`):
  физика → мозг → отрисовка. Опрос опор — отдельный таймер 2 Гц. Без
  фоновых потоков в v1: нечего синхронизировать.
- **Координаты — физические пиксели виртуального экрана** (PerMonitorV2),
  чтобы опоры из Win32 и позиция паука совпадали без пересчёта.
- **Опоры — только горизонтальные кромки** (верх окна, верх иконки, верх
  панели задач) плюс вертикальные бока для лазания. Паук не ходит по
  произвольным контурам.
- **Удаление — только `SHFileOperation` с `FOF_ALLOWUNDO`** после
  `RecycleBin.Check`; фильтр — отдельная чистая функция, тестируется первой.

## Risks and Mitigations

| Риск | Влияние | Митигация |
|---|---|---|
| `IFolderView` не отдаёт позиции иконок (другая оболочка, скрытые иконки, разная DPI) | Med | Task 6 изолирован; если не выйдет — паук живёт на окнах и панели задач, иконки откладываем. Запасной путь (чтение памяти Explorer) по спеку запрещён. |
| Layered window + drop target: OLE drop на `WS_EX_LAYERED` окне может не работать с `HTTRANSPARENT` | Med | В Task 11 непрозрачные пиксели возвращают `HTCLIENT`; проверить вручную в Task 1 на заглушке, если что — поднять раньше. |
| Мерцание/нагрузка при `SetWindowPos` 60 раз в секунду | Low | Двигать одно маленькое окно дёшево; замер CPU на каждом чекпоинте. |
| Удаление не того (системная папка, сеть → безвозвратно) | High | Фильтр (Task 10) с тестами до подключения удаления; `FOF_WANTNUKEWARNING`; ручная проверка только на файлах во `%TEMP%`. |
| Разные DPI на мониторах — смещение опор относительно паука | Med | PerMonitorV2 с первой задачи; ручная проверка на 100 % и 150 % на Checkpoint B. |
| Охота раздражает / мешает работе мышью | Low | Курсор не трогаем, кулдаун 20 с, пауза в трее. |

## Parallelization

Сессия одна, работаем последовательно. Независимы друг от друга (можно
переставлять): Task 6 ↔ Task 5, Task 10 — в любой момент после Task 1.
