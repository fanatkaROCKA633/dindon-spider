# SpiderWidget

Пиксельная голова на шести паучьих ногах живёт поверх рабочего стола Windows:
ходит по панели задач, кромкам окон и иконкам, лазает по ним, иногда
срывается и падает, охотится за курсором. Паука можно схватить мышью и
бросить, а если перетащить на него файл или папку, он их «съест» — отправит
в корзину.

## Требования

- Windows 10 21H2+ или Windows 11, x64.
- Для запуска готового `SpiderWidget.exe` —
  [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (x64).
- Для сборки из исходников — .NET 8 SDK:

```bash
winget install Microsoft.DotNet.SDK.8
```

После установки SDK откройте **новый** терминал: старый не увидит команду `dotnet`.

## Быстрый старт

```bash
git clone https://github.com/fanatkaROCKA633/Cool-spider-ilyuha.git
```

```bash
cd Cool-spider-ilyuha
```

```bash
dotnet run --project src/SpiderWidget
```

Паук появится посередине экрана и упадёт на ближайшую опору под собой.

## Собрать один exe

```bash
dotnet publish src/SpiderWidget -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Готовый файл: `src/SpiderWidget/bin/Release/net8.0-windows/win-x64/publish/SpiderWidget.exe`
(около 230 КБ). Его можно скопировать куда угодно и запускать двойным
щелчком — на машине нужен только .NET 8 Desktop Runtime.

Чтобы паук запускался вместе с Windows, положите ярлык на exe в папку
автозагрузки (`Win+R` → `shell:startup`). Сам виджет в автозагрузку себя не
добавляет.

## Управление

| Что сделать | Как |
|---|---|
| Выбрать голову | Правый клик по иконке-голове в трее → **Голова** → **Илюха** или **Диндон** |
| Поставить на паузу / продолжить | Правый клик по иконке-голове в трее → **Пауза** |
| Закрыть | Правый клик по иконке в трее → **Выход** |
| Схватить и бросить | Зажать левую кнопку на голове или ноге, махнуть мышью, отпустить |
| Уронить с места | Короткий клик по пауку без движения |
| Отправить в корзину | Перетащить файл, папку или ярлык на паука |

Выбранная голова запоминается и будет той же при следующем запуске.

Клики мимо паука (по прозрачной части его окна) проходят в окна под ним.
Фокус паук не забирает, в Alt-Tab и на панели задач его нет. Второй экземпляр
не запускается.

## Что умеет паук

- **Ходит** по панели задач, верхним кромкам окон и иконкам рабочего стола.
  Кромки, закрытые другими окнами, опорой не считаются.
- **Едет вместе с окном**, если окно под ним двигают; падает, если окно
  свернули или закрыли.
- **Лазает**: подходит к боковой грани иконки или окна выше себя (до 400 px
  выше и до 900 px в сторону) и забирается наверх.
- **Висит на иконках**, обхватив их ногами, и примерно раз в полминуты
  **срывается** и падает на опору ниже.
- **Охотится за курсором**: если курсор ближе 300 px, иногда подкрадывается,
  приседает и прыгает в точку, где был курсор. Не чаще раза в 20 секунд.
  Курсор паук не двигает и мышь не перехватывает.
- **Держится поверх всех окон**, в том числе окон «поверх всех», открытых позже.
  Меню Пуск, экран блокировки и полноэкранные игры перекрыть нельзя — это
  ограничение Windows.

## Корзина: что паук съест, а что нет

Всё, что бросили на паука, уходит **только в корзину** (из неё можно
восстановить), без вопроса «вы уверены?». Если Windows не может положить
объект в корзину (например, он слишком большой), она сначала спросит.

Перед удалением каждый путь проходит строгую проверку. Паук **отказывается**
(мотает головой, ничего не удаляет), если это:

- корень диска (`C:\`, `D:\`);
- `Windows`, `Program Files`, `Program Files (x86)` — сами папки, всё внутри
  них и папки, в которых они лежат (например, `C:\Users`);
- профиль пользователя, свой рабочий стол или общий рабочий стол целиком
  (файлы и папки **внутри** них удалять можно);
- сетевой путь (`\\server\...`, сетевой диск с буквой) или съёмный диск — у
  них нет корзины, удаление было бы безвозвратным;
- служебные и непонятные пути (`\\?\`, `\\.\`, относительные).

Ярлык удаляется как ярлык — программа, на которую он указывает, остаётся.
Ссылка на папку (junction) тоже удаляется сама, её содержимое не трогается.

Что съедено и что отклонено, пишется в локальный лог:
`%LOCALAPPDATA%\SpiderWidget\log.txt` (при размере больше 1 МБ начинается
заново, прошлый сохраняется как `log.txt.old`).

## Приватность

Виджет ничего не отправляет в сеть и не собирает данных. Положение окон и
иконок он только читает; в чужие программы не внедряется, их память не
читает, глобальных хуков клавиатуры и мыши не ставит. Пишет он только два
файла, оба на этом компьютере в `%LOCALAPPDATA%\SpiderWidget\`: лог выше и
`settings.txt` с выбранной головой.

## Настройка

Все числа поведения — в [`src/SpiderWidget/Spider/Tuning.cs`](src/SpiderWidget/Spider/Tuning.cs):
скорость ходьбы, шанс подъёма и срыва, радиус и частота охоты, сила броска.
После правки пересоберите проект.

Головы — пиксельные спрайты в [`src/SpiderWidget/Overlay/Sprites.cs`](src/SpiderWidget/Overlay/Sprites.cs):
строки символов и палитра цветов. «Илюха» сделан из фото, «Диндон» нарисован
по фото в мультяшном стиле. Чтобы добавить голову, опишите её спрайт (обычный и
с открытым ртом) и допишите строку в список `Sprites.Heads` — она сама появится
в меню. Высота головы может быть любой до 38 пикселей: ноги подстраиваются под
неё сами ([`src/SpiderWidget/Spider/Legs.cs`](src/SpiderWidget/Spider/Legs.cs)).

### Отладка опор

```bash
dotnet run --project src/SpiderWidget -- --debug-surfaces
```

Поверх экрана рисуются все опоры, которые видит паук: окна — синим, панель
задач — оранжевым, иконки — красным, пол — зелёным.

## Разработка

```bash
dotnet build SpiderWidget.sln -c Debug
```

```bash
dotnet test SpiderWidget.sln
```

```bash
dotnet format SpiderWidget.sln --verify-no-changes
```

Структура:

```
src/SpiderWidget/
  Program.cs        запуск, трей, один экземпляр
  Overlay/          окно паука, отрисовка, захват мышью, отладочная обводка
  Spider/           поведение (SpiderBrain), физика, ноги, настройки
  Targets/          опоры: окна, панель задач, иконки рабочего стола
  Recycle/          фильтр путей и отправка в корзину
  Native/           объявления Win32 / COM
tests/SpiderWidget.Tests/  тесты xUnit: физика, ноги, поведение, бросок, охота, фильтр путей
SPEC.md             спецификация
tasks/              план и список задач
```

Логика паука (физика, ноги, поведение, фильтр путей) не зависит от окна и
целиком покрыта тестами; окно только рисует и передаёт ввод.

## Известные ограничения

- Пока большая папка уезжает в корзину, паук замирает.
- Если Explorer завис, паук замирает вместе с ним (позиции иконок
  спрашиваются у Explorer).
- В момент «захвата» курсора (~0,3 с) клик схватит паука, а не уйдёт в окно под ним.
- За перетаскиваемым окном паук едет рывками — положение окон читается
  дважды в секунду.
- Отступ кромки иконок подобран на масштабе 125 %; на другом масштабе
  возможен сдвиг на пару пикселей. Несколько мониторов не проверялись.
